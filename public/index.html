Web Witness

An agent that observes web/API data, extracts a claim, signs it (Ed25519), and anchors its SHA-256 commitment on zkVerify — so "what the agent saw" becomes independently checkable, without archiving the full payload.

Witness a URL

Try: https://api.coinbase.com/v2/prices/BTC-USD/spot + data.amount  ·  https://api.github.com/repos/zkVerify/zkverifyjs + stargazers_count
Rate limited to a few requests per minute. Only public internet hosts — loopback/private ranges are rejected (SSRF guard).
